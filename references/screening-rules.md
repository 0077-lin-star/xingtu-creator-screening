# 初筛判断与数据采集口径

## 保留范围

默认状态为“初筛保留”“明显不符”“未完成初看”。初筛保留可附待用户复核事项，不使用“全部硬条件证实”作为进入明细的必要条件。用户自行完成最终核实，不能将初筛数量称为最终合格数量。

基本方向接近、没有明确严重冲突即可保留。价格带/销售量符合是加分，不满足或缺失不排除。其他数据的轻微偏差、范围不清、窗口无样本等记录出来；仅在证据明确触发当前用户不可放宽的条件，或表现出基本方向严重不符时排除。不得自创严重偏离的百分比。

## 条件使用

| 项目 | 初筛处理 |
| --- | --- |
| 内容/账号类型 | 快速判断基本方向，明显错误类型排除 |
| 价格带 | 默认加分项；保留实际区间与偏差，区分商品售价/客单价/达人报价 |
| 销量 | 默认加分项；缺失/不足不淘汰，区分件数、订单数与GMV |
| 商单完播 | 保留既有5%参考条件及本次要求；无样本或未充分确认可保留并标注，不能用个人完播替代 |
| 月深度用户/粉丝 | 记录实际值与关系供用户复核；默认初筛不沿用旧版“一低于即排除”，除非本次明确为不可放宽条件 |
| 女性/八大人群/CPM | 按本次brief记录目标与实际值；明显背离基本受众或明确一票否决可排除，边界/缺失保留说明 |
| 结算价 | 用户手填，整列保持空白 |

例如项目明确面向女性而账号内容及受众主体明显相反，可排除；女性比例仅略低于参考值而内容基本匹配，不自动排除。用户明确“低于某值绝不收”时按该规则执行。不要因旧表头“>50%”给所有项目设置该门槛。

## 抄数必须正确

初筛减少的是终审深度，不减少真实数据要求。确认账号ID和当前页面后读取；昵称相同不能互借数据。每个值保留原标签、原文/单位、统计窗口、视频规格、流量排除状态、来源与时间。

- 商单必须是星图视频数据。无商单时页面可能自动显示个人视频，此时商单列留空并说明无样本；账号仍可初筛保留。
- 预估CPM/CPE与自然实际指标分别记录。预估值放资料说明，不冒充原26列自然量CPM/CPE。
- 商业能力、效果预估、创作曲线的排除营销开关各自核对。无法确认排除状态的数值不能填入声称排除广告的正式列，原值和缺口可记资料说明。
- 有“只看指派”限制且用户未要求时取消，记录最终状态；没有控件则记录实际页面范围。
- 报价、预估效果对应同一视频规格。未指定规格可统一当前常用规格并说明执行采用，不取不同规格的有利数字拼接。
- 时间范围尽量统一；30天无样本不冒充有，90天补充值单独注明，不替换30天字段。
- “<5条”保留范围，不写成5或0。未知与0分开。已是万单位不再除10000；粉丝指数保存原标签和近似精度。
- 比较符号和原始阈值不改写；临界四舍五入的数值标注边界不清，无需在初筛反复追查。
- 列表和详情不一致时快速核对范围/时间，优先保留正确口径的当前详情；无法解释留双方来源和待复核，不取有利值宣称达标。

只做有明确成本分子、同样本的合法计算。没有成本/互动口径，实际CPM、CPE、完播CPM留空，不用报价或预估随意拼算。没有月初基数不倒推月涨粉率。

## 近期15条表现

采集平台近15条播放局部图，保留日期轴、图例和排除营销状态。不足15条如实注明。默认无需逐条转录45项数据、计算复杂趋势或完整审片。

页面直接可见明显波动、回落或商单与个人样本差距时，可写一句客观提示；没有观察到足够信息则交用户复核。新作品曝光时间短，不能凭最后一个低点认定衰退。曲线样本与商业能力时间窗不互换。

## 联系与缺失

所有保留账号都实际尝试简介、公开联系/微信及适用MCN商务入口。不因为价格或销量偏差、指标待确认而跳过后续采集。标注达人或机构归属、明确微信或仅商务标识；未公开不猜测，也不发送消息索取。

缺失分别写未采集、未展示、无样本、权限受限、口径不清、需商务确认、用户手填。遇到失败有限重试，不在单个非关键字段耗尽时间。采集完仍有真实缺失就交付说明，不无限扣住候选。

## 数量与资料完整度

交付数量按已初看基本匹配且已写入明细的唯一账号计数，含留待用户复核事项者；不包含无关线索、重复ID、公司或仅发现未初看的账号。四图齐全、联系信息取得数量另算，不把“写了缺失原因”称为资料齐全。

用户明确启动严格复核时，再对指定不可放宽条件逐项判定；初筛表不会因为尚未完成此步骤被清空。保留原记录与新评价，不把用户待办包装成已完成审核。
