# 星图达人筛选 Skill

根据品牌 brief 或达人画像，在星图批量寻找基本匹配的达人，采集数据、局部截图和公开商务联系方式，交付整洁的 Excel 明细，供媒介进一步复核。

当前版本：**v1.3 公开通用版**。

## 功能

- 从零寻找账号，或整理用户给定的达人名单。
- 区分基本方向、明确排除项和加分项。价格带与销量默认用于排序，用户明确硬限制时按当前要求执行。
- 交付26列达人明细，按适配程度排序，附简短理由、资料来源和缺失说明。
- 每个候选采集粉丝年龄、观众八大人群、粉丝性别及近15条播放曲线，直接嵌入对应单元格。
- 点击主页“联系 → 查看微信”，同时展开简介，采集公开商务联系方式。
- 按账号记录采集、保存、入表与缺口状态，逐行检查，减少漏图、漏写联系方式和错账号资料。

## 使用条件

这是供支持Skill的AI助手读取的工作流程文件。运行时需要可控制浏览器、可访问的星图账号，以及能生成嵌图Excel的工具。仓库不包含自动爬虫、浏览器驱动、账号登录态或独立Excel生成程序。

将仓库文件放入当前助手的技能目录，保持文件夹名为 `xingtu-creator-screening`，并确保 `SKILL.md` 位于该文件夹根目录。已有同名Skill时先保留自己的项目配置，再更新通用文件。由助手确认技能已加载后使用下方指令。

## 调用示例

```text
使用 $xingtu-creator-screening。
项目 brief：[粘贴需求或提供附件]
目标数量：30个基本匹配候选
总时限：60分钟
明确排除项：[填写不可放宽的条件]
加分项：[填写偏好]
输出目录：[本地目录]

按26列达人明细交付Excel。截图嵌入对应单元格，
联系方式查看“联系 → 查看微信”并展开简介。
最终内容和商务条件由我复核。
```

没有参考账号也可按brief执行。项目条件优先于默认值。未指定数量和时限时，默认目标为200个基本匹配候选、60分钟总时限；这是工作目标，实际产能取决于页面加载、登录状态和资料可得性，不能保证达成。

## v1.3 更新

明确查看微信属于资料读取；采集与导出使用一致字段；区分未采、失败、已保存和已嵌入；逐账号核对四图与联系方式。基本匹配账号不因资料缺失自动删除。

公开版保留通用流程，移除了客户专属配置、具体达人样本数据和本机路径。客户brief、联系方式、截图、Excel、运行日志和浏览器资料应保存在仓库外。

登录和验证由用户完成。采集联系方式不自动授权发送消息、邀约、询价或下单。表中数据按实际来源填写，未知不填0，也不编造号码或图片。
